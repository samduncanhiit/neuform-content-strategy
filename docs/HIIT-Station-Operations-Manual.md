## 7. MONEY & PAYMENTS

### Cash Drawer Reconciliation (daily)

1. Run MindBody report: Reports > Sales > Cash Drawer > select date > HIIT Station Capalaba > GO
2. Cross-check EFT & Cash totals against envelope contents AND back-end payments
3. If discrepancy found: investigate, note on envelope, escalate to Michelle if significant
4. Give envelopes to Allexis weekly on Mondays for Michelle at the Warehouse
5. Keep sufficient notes and coins in safe — request change from Michelle if needed

### Stripe Payments (after hours)

1. Check Stripe (dashboard.stripe.com) for any after-hours QR code purchases
2. Login > Transactions > check current date
3. Complete a Stripe receipt (date, client, stock, amount)
4. Process in MindBody as "STRIPE PAYMENT"
5. Put receipt in till for end-of-day matching

### Account Arrears Process (every Friday)

1. MindBody > Reports > Clients > Account Balance > generate > export to Excel > copy to arrears spreadsheet
2. Also run: MB Dashboard > Failed Autopays > generate > export > copy to spreadsheet
3. **Filter out challenge participants** who owe for upcoming challenges
4. Contact clients based on escalation level (1st, 2nd, 3rd attempt)

### Debt Collection (after 3 failed attempts)

1. Add client details to Debt Collection spreadsheet
2. Email spreadsheet to consumer@armagroup.com.au
3. Place open-ended suspension on MindBody account (no further payments, no class bookings)
4. Wipe debt from MindBody
5. Add alert flag on MB account regarding debt collection
6. Update Debt Collection spreadsheet
7. Notify Office Chat about new debt collection clients
8. Check ARMA portal every 3 months for updates
9. Once debt cleared: remove alert, release suspension, terminate membership

## 10. 8-WEEK CHALLENGE

HIIT Station runs back-to-back 8-week body transformation challenges. Managed via the "HIIT Challenge" Trello board and Google Calendar.

### Challenge Trello Board Structure

- **CHALLENGE QUICK INFO:** Key dates, pricing, overview
- **NEW WAY TO RUN CHALLENGE:** Weekly to-do lists (Weeks 1–7 + pre-challenge)
